# Wireshark installation guide for MacOS

Start by going to the download page on the [Wireshark website](https://www.wireshark.org/download.html), and download the most recent version for MacOS.  

<img width="1005" height="383" alt="1" src="https://github.com/user-attachments/assets/663e6495-1a91-4342-840d-03763c3e21eb" />

\
Once the download is complete, launch the **.dmg** file. You should have the following screen. 
<img width="472" height="662" alt="2" src="https://github.com/user-attachments/assets/7692bf0e-b1cc-47e6-ad50-dd47c33e4051" />

\
Here, you should:
1. Drag the Wireshark app to the Application folder
2. Double click on "install ChmodBPF"
3. and Double click on "Add Wireshark to the System path"

The install is now complete. You can launch Wireshark from your Applications launcher. 

<img width="1210" height="733" alt="3" src="https://github.com/user-attachments/assets/2190072c-7fb1-4a76-8830-ebc78564d41b" />

\
To capture the packet going over your Mac's WiFi, you may double click on the "en0" port:

<img width="1254" height="777" alt="4" src="https://github.com/user-attachments/assets/f5909fbb-4afd-48a6-bc83-ec713ce0eff6" />

\
This guide is now complete!
